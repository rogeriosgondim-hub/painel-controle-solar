Como funciona

A versão 2.1 Premium usa uma área separada do seu repositório GitHub (branch cloud-sync) como armazenamento. Antes do envio, os dados são criptografados no aparelho com AES-GCM. A senha de criptografia e o token do GitHub não são enviados para o repositório.
Importante: use um token GitHub fine-grained, restrito somente ao repositório painel-controle-solar, com permissão Contents: Read and write. Não envie esse token pelo chat.

Configuração deste aparelho

A configuração fica somente neste navegador/celular e não entra no backup dos dados.
