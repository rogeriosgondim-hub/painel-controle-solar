# Controle Solar — Android

Aplicativo Android offline que incorpora o Painel de Controle Solar.

- Pacote: `br.com.controlesolar.residencia`
- Versão: 1.0
- Min SDK: Android 7.0 (API 24)
- Dados: armazenados localmente no WebView do aplicativo
- Backup JSON e exportação CSV: usam o seletor nativo de arquivos do Android
- Importação de backup: usa o seletor nativo de arquivos

O APK de teste é gerado pelo workflow `Build Android APK`.
