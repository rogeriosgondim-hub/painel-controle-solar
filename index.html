Como o consumo é calculado

Consumo da rede = (leitura atual − leitura anterior) × multiplicador. Confira o fator na fatura; use 1 quando a leitura já estiver em kWh. Esse consumo é a energia recebida da Enel e não inclui a energia solar usada diretamente na residência.

Opcional

Durante o ciclo, registre suas leituras em Relógio Enel. Preencha a data e a leitura de fechamento quando receber a próxima fatura.

Para acompanhar, preencha a data anterior e a leitura anterior acima.

Quando posso usar as leituras 03?

Use leituras do mesmo medidor da fatura. Os números precisam seguir a mesma unidade e o mesmo fator das leituras anterior e atual informadas acima. Se o visor já mostra kWh e a fatura usa uma leitura com multiplicador, confira essa correspondência antes de ativar. Se o medidor foi trocado, registre um novo início.

Parâmetros do sistema

Os dois campos marcados em vermelho são os ajustes operacionais previstos na planilha.

Backup e portabilidade

Leve seus lançamentos para outro computador ou celular.

Prefira o backup com senha para guardar seus registros. A senha não pode ser recuperada. O backup simples, Excel, CSV e PDF contêm dados legíveis. As credenciais da nuvem não entram nos backups.

A fatura da distribuidora continua sendo a referência oficial de cobrança. Este app reproduz a lógica de gestão da planilha e não substitui os dados oficiais.

Como funciona

O painel usa uma área separada do seu repositório GitHub (branch cloud-sync) como armazenamento. Antes do envio, os dados são criptografados no aparelho com AES-GCM. A senha de criptografia e o token do GitHub não são enviados para o repositório.
Importante: use um token GitHub fine-grained, restrito somente ao repositório painel-controle-solar, com permissão Contents: Read and write. Não envie esse token pelo chat.

Configuração deste aparelho

No Android, as credenciais são protegidas pelo sistema. No navegador, desbloqueie a sincronização com sua senha a cada sessão. A configuração não entra no backup dos registros.

Compatibilidade do Relógio Enel

Identifique o modelo do medidor na etiqueta e selecione-o na tela Relógio Enel. O reconhecimento especializado do Nansen Vector 4 está em validação; outros modelos ainda não foram validados.

Antes de lançar, confirme no manual ou com a concessionária o significado dos códigos. Não considere 03 e 103 universais. Registre os totais acumulados confirmados em kWh, sem subtrair a leitura anterior. Confira o valor antes de salvar.

Para residências diferentes, mantenha históricos e credenciais de sincronização separados.
